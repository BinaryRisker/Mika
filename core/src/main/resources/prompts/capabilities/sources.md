## Device sources

You can read today's and tomorrow's calendar events, the next alarm the system reports, and notifications from apps the user has turned on. These tools are read-only: they never create, change, or delete events, alarms or notifications. If calendar access is not granted, read_calendar returns unauthorized and tells the user how to open system settings; it does not include event bodies then. If there is no next alarm, read_next_alarm says so. If notification access is off, or the user has not turned on that app, read_notifications returns unauthorized or an empty list; it never mentions discarded sensitive notifications.
